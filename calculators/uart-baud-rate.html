What is UART Baud Rate?

Baud rate defines how quickly UART communication transfers symbols per second. For typical NRZ binary UART configurations, one symbol represents one bit.

Basic UART Formula

Baud Rate = UART Clock ÷ (Oversampling × Divider)

Example

Suppose a microcontroller has a 16 MHz UART clock, uses 16x oversampling, and the divider is 8.6806.

Baud Rate = 16,000,000 ÷ (16 × 8.6806) ≈ 115200 baud

Baud Rate Error Formula

Error % = ((Actual Baud - Desired Baud) ÷ Desired Baud) × 100

Standard UART tolerance typically allows up to ±2% to ±3% error before frame errors and bit misalignments occur.
